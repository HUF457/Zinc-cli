# Zinc 0.7.4

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.7.4-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.7.4.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.7.4.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.7.4-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.7.4-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Text looks like it did before 0.7.3.** 0.7.3 moved the visible tab to the
  GPU (WebGL) renderer, and its text came out thinner and lighter than the
  DOM renderer's. Terminals now use the DOM renderer by default again.
- **GPU rendering is an opt-in setting** (Settings → "GPU rendering"). It is
  lighter for a tab that redraws constantly. When it is on, glyphs are drawn
  at Medium weight, which brings their ink coverage within 2% of the default
  renderer's (measured with JetBrains Mono 17 px at 150% scaling, in light and
  dark themes). Cell widths are rounded to whole device pixels, so spacing can
  still differ very slightly. If WebGL is unavailable or the GPU context is
  lost, Zinc falls back to the DOM renderer.
- Hidden tabs still stop painting (their output is still read and is current
  when you switch back). That is where most of 0.7.3's responsiveness gain
  comes from, and it does not depend on the GPU setting.

The upgrade acceptance path is pinned to the reviewed public `v0.7.3` setup.
