# Zinc 0.8.3

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.8.3-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.8.3.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.8.3.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.8.3-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.8.3-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

0.8.3 follows 0.8.2 within the day.

- **Group by dragging.** Drag a tab onto the middle of a tab that is not in a
  group and rest there: the target is outlined. Let go and the two become a new
  group whose name field opens. Letting go without the pause still just moves
  the tab.
- **Fixed: a tab stayed in the wrong auto group.** A tab started as
  `cd project; claude` on one line used to stay in the group of the folder it
  was opened in, because PowerShell only reported its folder at the next prompt.
  PowerShell now reports on every `cd`, and while an AI CLI runs its own folder
  is used.
- **Thinner icons.** The line is 1.5 instead of 2 units, closer to the text
  beside it.
- **Fixed: colours that ignored the scheme.** The turning ring's track, the
  switch knob and the update button text now follow the colour scheme, and the
  terminal scrollbar follows the light / dark theme.

The upgrade acceptance path is pinned to the reviewed public `v0.8.2` setup.
