# Zinc 0.7.3

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.7.3-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.7.3.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.7.3.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.7.3-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.7.3-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **The window stays responsive with many busy tabs.** Hidden tabs used to
  keep repainting everything their programs printed, all on the one thread
  that also handles your typing and scrolling — with several Claude Code tabs
  working at once, the visible tab stuttered. Hidden tabs now stop painting
  (their output is still read and is up to date when you switch back). In our
  benchmark (development build, nine background tabs running a simulated
  Claude-style redraw), the interface thread went from 88% busy to 15%, and
  95th-percentile keystroke latency from 80 ms to 32 ms.
- **The visible tab draws through the GPU** (xterm.js WebGL renderer), which
  cut the cost of a constantly redrawing tab to roughly a quarter in the same
  benchmark. If WebGL is
  unavailable or the GPU context is lost, Zinc falls back to the previous
  renderer automatically.
- Animated tab titles (such as Claude Code's spinner) are applied in batches
  at most four times a second, and the hidden Settings page no longer
  re-renders with them.
- Fixed a background tab that finished starting late taking keyboard focus,
  so typing went to an invisible tab.
- Fixed wrong colors with the transparent terminal background: a foreground
  color whose value happened to contain 40 could be turned into a background
  change, and colors could apply to the wrong text depending on how output
  was split.
- Scrolling up while a program prints now stays where you put it.
- The "process exited" line now always appears after the program's final
  output, and an exited tab still re-fits when the window is resized.
- Programs can query the terminal's background color again.
- Pasting a large image no longer blocks the window while the file is saved,
  and periodic session saving reads its files once per round instead of once
  per tab.

The upgrade acceptance path is pinned to the reviewed public `v0.7.2` setup.
