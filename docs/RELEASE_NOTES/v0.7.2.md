# Zinc 0.7.2

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.7.2-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.7.2.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.7.2.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.7.2-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.7.2-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Claude tabs whose conversation moved to the background come back to that
  live conversation.** Claude Code can move a conversation into a background
  job (the agents view, `←`), which continues it under a new session ID. Zinc
  kept the old ID, so the next start either reopened an outdated copy while
  the job kept running, or stopped with "is running in the background … stop
  it there first to resume it here". Restore now follows Claude's hand-off
  record: a job that is still running is reopened with `claude attach`, and a
  job that has ended resumes its newest copy in the tab. Zinc never starts,
  stops or changes a background job, and if `claude agents` cannot be queried,
  restore behaves exactly as in 0.7.1.

This is a bug-fix release; everything else is unchanged from 0.7.1.

The upgrade acceptance path is pinned to the reviewed public `v0.7.1` setup.
