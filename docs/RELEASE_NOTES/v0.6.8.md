# Zinc 0.6.8

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.8-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.8.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.8.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.8-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.8-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- **Kimi full-screen wheel paging** now owns the wheel: one Windows notch is
  one page. The previous build also let xterm line-scroll the same gesture,
  so the conversation twitched instead of paging.
- Installer upgrade matrix is pinned to the reviewed public `v0.6.7` setup.
