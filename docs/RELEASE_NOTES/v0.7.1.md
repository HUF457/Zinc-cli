# Zinc 0.7.1

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.7.1-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.7.1.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.7.1.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.7.1-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.7.1-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Tabs whose Claude conversation was already quit now resume that
  conversation.** A conversation lives on disk, so the absence of a running
  Claude process no longer discards the tab's saved conversation ID. In
  0.7.0 only the tabs whose Claude was still running came back; tabs left idle
  for hours reopened as plain shells. A freshly started Claude process that
  cannot report its ID still drops the previous one, so a new process never
  inherits an old conversation.

This is a bug-fix release. The 0.7.0 features — separate Claude conversations
per tab under one directory, the per-process session hook, and the conservative
reopen when an identity is unknown — are unchanged.

The upgrade acceptance path is pinned to the reviewed public `v0.7.0` setup.
