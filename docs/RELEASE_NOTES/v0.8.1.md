# Zinc 0.8.1

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.8.1-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.8.1.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.8.1.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.8.1-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.8.1-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

0.8.1 is a settings-page cleanup on top of 0.8.0; nothing outside Settings and
corner shapes changes.

- **A "Tabs & AI" page.** Auto-group by project, Precise AI status and Image
  paste move there from the Terminal page, which keeps font, cursor and
  performance. "Group tabs by project" is now "Auto-group by project" and "Grok
  full-screen surface tint" is "Grok full-screen tint".
- **Shorter settings text.** A description stays only where the title and the
  options do not already say it.
- **One set of corner radii.** Cards, menus, dialogs, toasts and the window card
  are 8 px; fields, buttons and rail rows are 4 px.
- **Fixed: the Image paste dropdown ran past the edge of its card.** A long
  description now stays beside the control instead of pushing it onto its own
  row.

The upgrade acceptance path is pinned to the reviewed public `v0.8.0` setup.
