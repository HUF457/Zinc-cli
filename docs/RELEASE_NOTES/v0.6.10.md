# Zinc 0.6.10

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.10-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.10.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.10.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.10-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.10-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

One fix, reproduced and verified against the running application.

- **Inverse terminal text no longer renders as a solid, unreadable bar on
  light colour schemes.** A TUI can ask for reverse video (`SGR 7`) without
  naming either colour — Claude Code styles whole message blocks that way.
  xterm then paints the cell with the theme's *foreground* colour as its
  background, and derives the glyph colour from the theme's *background*.
  Zinc had to hand xterm a fully transparent background so the OS Acrylic
  material shows through the terminal card, and xterm's own conversion of a
  transparent colour to an opaque one composites onto black — so the text came
  out pure black on a near-black cell. On a dark scheme that is invisible
  because it is nearly correct; on a light scheme it is a solid dark bar with
  the message hidden inside it.

  Two changes fix it: an opaque terminal card now gives xterm the colour
  scheme's real surface colour instead of transparency, and a stylesheet rule
  supplies that same colour for inverse text when the card is see-through and
  the theme background must stay transparent. A new CDP smoke
  (`npm run verify:cdp:inverse`) measures the rendered contrast of an inverse
  run across both light and dark schemes at three opacity settings, and
  includes a negative control that restores the old values and asserts the bar
  comes back.

Installer upgrade matrix is pinned to the reviewed public `v0.6.9` setup.
