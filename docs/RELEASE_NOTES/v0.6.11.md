# Zinc 0.6.11

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.11-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.11.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.11.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.11-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.11-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

One optional setting.

- **Grok full-screen surface tint** (Settings → Appearance, off by default).
  Grok Build's TUI paints every cell of its own canvas in its own grey. Until
  now the only way to stop Zinc's terminal card from framing that canvas in a
  different colour was to switch the whole application to the Grok colour
  scheme, which changed every other tab as well.

  With this setting on, a tab takes Grok's surface colour for as long as Grok's
  full-screen TUI is on screen, and gives it back the moment the TUI exits. The
  tab rail, the ANSI palette, and every other tab keep the colour scheme you
  picked. The change fades over ~220 ms in both directions, and xterm's own
  background moves with the card so the canvas and the padding around it never
  disagree mid-transition.

  The setting is deliberately inert at terminal opacity 0: there the card is
  raw Acrylic and Grok's near-black background is already rewritten to the
  transparent default, so canvas and frame already match.

  A new CDP smoke (`npm run verify:cdp:grok`) drives a real alternate-buffer
  switch and asserts that the card background, xterm's theme background, and
  the inverse-text colour all move together — and that nothing moves with the
  setting off or at opacity 0.
