# Zinc 0.7.0

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.7.0-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.7.0.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.7.0.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.7.0-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.7.0-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Separate Claude conversations in one directory can return to their own
  tabs.** When session restore and AI conversation resume are enabled, Zinc
  saves each tab’s Claude session ID and launches an exact resume on restart.
  A per-process SessionStart hook records the ID without changing the user’s
  global Claude settings. Directly typing `claude` at an interactive PowerShell,
  Command Prompt, or Git Bash prompt is covered. Full-path executable launches,
  scripts, and manually launched WSL Claude sessions are **not** covered; a tab
  without a trustworthy ID reopens conservatively rather than taking another
  tab’s conversation. This also applies if the working directory no longer
  exists.
- Shutdown saves, running-tool recognition, and shell discovery are more
  robust. Error handling is improved for update checks, pasted-image paths,
  and external links.

The upgrade acceptance path is pinned to the reviewed public `v0.6.11` setup.
