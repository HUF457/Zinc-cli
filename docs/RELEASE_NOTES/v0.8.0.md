# Zinc 0.8.0

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.8.0-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.8.0.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.8.0.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.8.0-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.8.0-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

- **Tab groups.** Gather tabs into groups in the rail. A group header collapses
  and expands (with a short animation) and can be renamed or dissolved from its
  menu; collapsed, it shows how many tabs it holds and the status that most
  needs you. Drag a tab into, out of or within a group, or drag a whole group;
  rows slide aside while you drag and Esc puts everything back. Groups, their
  names, whether they are collapsed and your tab renames are restored after a
  restart.
- **Automatic grouping by project.** Tabs working in the same project folder
  (the Git root, else the folder itself) are grouped for you, titled after the
  folder: Claude Code launched there, or a shell that `cd`s into it. A tab you
  have dragged, grouped or taken out yourself is never moved again; "Group
  automatically" in its menu hands it back. Settings → "Group tabs by project"
  (on by default) turns it off. The first launch after updating groups the tabs
  you reopen, so expect the rail to rearrange once.
- **Status icons for AI sessions.** A tab running an AI CLI shows working
  (spinning), waiting for you, done or failed; a collapsed group shows the most
  urgent one. Settings → "Precise AI status" (on by default, new tabs only)
  lets Claude Code report these exactly by running the tab on the console host
  bundled with Zinc; off, only working and idle are guessed from the title. A
  tab whose title is only a spinner or a default AI name shows its project
  folder instead.
- **Image paste goes straight to the CLI.** Ctrl+V with an image on the
  clipboard hands it to Claude Code, Codex, Kimi or Grok, which read the
  clipboard themselves (shown as `[Image #1]`); Zinc saves nothing. A plain
  shell or WSL, or Settings → Image paste → "Always save as a file", still
  pastes the path of a saved copy.
- **Lighter on memory.** All terminals share one output-reading worker: about
  81 MB less with 12 tabs open and about 135 MB less with 20 (development-build
  measurement). A fresh install starts with 3000 lines of scrollback instead of
  10000 (a stored value is kept). The working icon turns in steps, so a window
  full of working sessions no longer keeps the GPU busy.
- **Removed: wheel paging for Kimi's fullscreen mode.** With Kimi's
  `tui_mode = "fullscreen"` the mouse wheel now recalls Kimi's input history
  instead of scrolling.

The upgrade acceptance path is pinned to the reviewed public `v0.7.4` setup.
