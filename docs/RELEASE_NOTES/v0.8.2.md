# Zinc 0.8.2

Zinc is a **lightweight multi-shell Windows terminal launcher** with a vertical
tab rail, an Acrylic-style window, PowerShell-first shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.8.2-Setup.exe`** is the only installer. It installs per user by
default; a normal install does not require administrator rights.

Zinc updates itself, so most people will pick this up through the in-app
updater. If you install manually, download the setup below.

The other assets document the build: `SHA256SUMS.txt`,
`zinc-0.8.2.cdx.json` (CycloneDX SBOM),
`THIRD_PARTY_NOTICES-0.8.2.md`, `ASSET_PROVENANCE.md`, `LICENSE`, and the
`latest.yml` / `.blockmap` files used by the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.8.2-Setup.exe -Algorithm SHA256
```

Compare the result with the `Zinc-0.8.2-Setup.exe` line in `SHA256SUMS.txt`
from this release. If it matches, use **More info → Run anyway** if Windows
SmartScreen prompts. If it does not match, do not run the file.

## What changed

0.8.2 is a visual update on top of 0.8.1.

- **A new icon set.** Tab status, the group arrow, buttons and the settings
  pages are drawn in one 2 px rounded stroke instead of the thin Windows system
  glyphs.
- **A smooth "working" ring.** It turns continuously instead of stepping, and
  turns about its own centre, so it no longer wobbles in its slot.
- **Five new colour schemes,** each with a light and a dark version: Ink (the
  default, formerly Monochrome), Abyss, Sakura, Matcha and Amber. Every text
  colour reads at 4.5:1 or more on its own background. A scheme saved by an
  earlier version switches to the nearest new one.
- **Fixed: faint text on AI CLI backgrounds.** Text an AI CLI draws on its own
  background colour (for example Claude Code's diff rows) is lightened or
  darkened when it would be too faint to read.

The upgrade acceptance path is pinned to the reviewed public `v0.8.1` setup.
