# Zinc 0.6.5

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.5-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.5.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.5.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.5-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.5-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- **Session restore while running**: Zinc now writes `session-state.json` on a
  short interval and after tab changes, not only on a clean quit. A crash or
  power loss can still restore the last saved tabs.
- **Sticky directories and AI tools**: a later process-tree miss no longer
  clears a tab back to the wrong PowerShell cwd or `Tool.None`.
- **Codex resume**: multiple Codex tabs no longer each run `codex resume --last`.
  A session id from the process command line is used when present; otherwise
  only the last-active Codex tab gets `--last`.
- Installer upgrade matrix is pinned to the reviewed public `v0.6.4` setup.
